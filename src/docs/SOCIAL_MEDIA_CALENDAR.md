## 📱 BUFFER/HOOOTSUITE IMPORT INSTRUCTIONS

### For Buffer:
1. Go to buffer.com
2. Click "Create Post"
3. Copy/paste each caption above
4. Add corresponding images
5. Schedule for recommended times
6. Add links in appropriate fields

### For Hootsuite:
1. Go to hootsuite.com
2. Click "Create Post"
3. Select all social networks
4. Copy/paste captions
5. Upload images
6. Use scheduling calendar
7. Set times in AEST timezone

### Best Practices:
- **Images:** Use high-quality photos (1080x1080 for Instagram, 1200x630 for Facebook/LinkedIn)
- **Videos:** Keep under 60 seconds for feed, 15-30 seconds for stories
- **Links:** Always include trackable links
- **Hashtags:** Use 5-10 for Instagram, 2-3 for Facebook/Twitter, 3-5 for LinkedIn
- **Engagement:** Respond to comments within 2 hours during business hours

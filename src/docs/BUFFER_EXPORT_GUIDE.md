## PLATFORM-SPECIFIC OPTIMIZATIONS

### Instagram:
- **Image Size:** 1080x1080 (square) or 1080x1350 (portrait)
- **Hashtags:** 5-10 in post or first comment
- **Link:** In bio (use Linktree if multiple links needed)
- **Best Times:** 7-9am, 12-1pm, 7-9pm AEST

### Facebook:
- **Image Size:** 1200x630 (landscape)
- **Hashtags:** 2-3 maximum
- **Link:** Direct link in post
- **Best Times:** 1-4pm, 7-9pm AEST

### Twitter/X:
- **Image Size:** 1200x675 (16:9)
- **Hashtags:** 3-5
- **Link:** Shortened link (bit.ly or t.co)
- **Thread Format:** Break long posts into 2-3 tweets
- **Best Times:** 8-10am, 6-9pm AEST

### LinkedIn:
- **Image Size:** 1200x627 (landscape)
- **Hashtags:** 3-5 professional tags
- **Link:** Direct link
- **Tone:** More professional, business-focused
- **Best Times:** 7-9am, 12pm, 5-6pm AEST (weekdays)

### TikTok:
- **Video Size:** 1080x1920 (9:16 vertical)
- **Duration:** 15-60 seconds
- **Hashtags:** 3-5 trending + niche
- **Link:** In bio only
- **Best Times:** 6-10pm AEST
